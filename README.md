# 💈 Fila de Espera - Barbearia

## 📌 Sobre o Projeto

O **Fila de Espera - Barbearia** é um sistema desenvolvido para gerenciar e organizar o fluxo de clientes em uma barbearia. Ele substitui as anotações manuais por uma solução digital simples, permitindo acompanhar a ordem de chegada e o status dos atendimentos.

## 🎯 Objetivo

Facilitar a rotina dos barbeiros e organizar o tempo dos clientes, garantindo que o atendimento seja feito de forma rápida, justa e sem confusões na fila.

## ⚙️ Como Funciona

1. **Entrada do Cliente:** O nome do cliente é adicionado à fila com o horário de chegada e o serviço desejado.
2. **Acompanhamento:** A lista exibe em tempo real quem está sendo atendido e quem são os próximos.
3. **Gerenciamento:** O atendente altera o status do cliente (em espera, em atendimento ou concluído) conforme o serviço é realizado.
